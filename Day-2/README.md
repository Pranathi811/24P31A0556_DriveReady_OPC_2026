# Day 2 – Python Concepts: Prompts, Memory and Data Handling

## Task Description

This task focuses on implementing fundamental Python concepts used in building intelligent AI assistants. It demonstrates how prompts, conversation messages, examples, memory, JSON data handling, functions, decorators, and exception handling can be used to develop a simple bakery assistant for Sweet Crumbs Home Bakery.

The implementation uses practical examples related to cake flavours, pricing, customer information, and order details to understand how an AI assistant can manage conversations and store information.

## Key Concepts Implemented

1. **Message Structure:** Understanding system, user, and assistant messages in a conversation.
2. **System Prompts:** Defining the assistant's role, behaviour, rules, and response format.
3. **Few-Shot Prompting:** Using input-output examples to demonstrate the expected assistant responses.
4. **JSON Data Handling:** Creating and formatting structured customer order information using Python's JSON module.
5. **Memory Management:** Storing and retrieving customer details such as name, favourite cake, city, and favourite colour using dictionaries.
6. **Dictionary Operations:** Creating, accessing, adding, and updating student and customer information.
7. **Python Functions:** Implementing reusable functions to retrieve cake prices.
8. **Decorators:** Demonstrating how decorators add additional functionality before and after function execution.
9. **Exception Handling:** Handling errors such as division by zero, invalid input, and unavailable cake flavours.

## Implementation Overview

The task begins by creating a conversation message structure for a bakery assistant. A system prompt is then designed to establish the assistant's role and ensure that responses follow the provided bakery information.

Few-shot examples demonstrate how the assistant should respond to common customer questions. Python dictionaries are used to store customer details and student information, while JSON serialization and deserialization demonstrate structured data conversion.

Functions are implemented to retrieve cake prices based on cake flavours. Decorators demonstrate additional function behaviour, and exception handling ensures that common runtime errors are managed properly.
